# Chess Game Analytics & Cheat-Detection Warehouse

DWM mini project - data warehousing, OLAP and data mining applied to online chess game data.

## Structure
- db/ - warehouse schema (star schema DDL)
- etl/ - extract, transform, Stockfish-enrich, load pipeline
- mining/ - association rules, clustering, classification, outlier detection
- backend/ - FastAPI serving OLAP queries + mining/ML results
- frontend/ - React dashboard
